# Тропа троллей

Браузерная игра по исходным правилам: «Трям» — шаг вперёд, «Бум» — прыжок вперёд, «Ля» — вправо, «Оп» — влево, «Бах» — замереть на пять счётов. Три жизни; ошибка не сдвигает персонажа и не пропускает ожидаемую команду.

При открытии игры появляется вступление из четырёх коротких страниц: Тишка заблудился, секретная тропа троллей, пять слов и правила с сердечками. Можно послушать страницу, нажать слово для озвучки его значения, вернуться назад или пропустить вступление. Кнопка «Начало сказки» открывает историю заново. Приглашение на экскурсию показывается после вступления. Кнопки команд и варианты в загадке состоят из текста без иконок направлений.

В игре две главы и десять уровней. Первая глава — Волшебное болото, вторая — Лунная речка. На уровнях 6–10 нужно запоминать маршруты по 6–8 слов. Все маршруты используют максимум три разных слова, не более трёх повторов одного слова в одном отрезке, и проверены на проходимость.

Тишка общается с ребёнком короткими репликами и ответами-кнопками. В настройках можно указать имя только на текущее занятие и включить голос через Speech Synthesis браузера. Микрофон не используется. Качество и доступность русской озвучки зависят от голосов браузера/системы; текст работает всегда.

Между маршрутами есть открытия и задания «Помоги Тишке вспомнить»: ребёнок выбирает правильное значение слова. В загадках жизни не теряются; есть подсказка и пропуск. Сюрпризы можно отключить. Светлячки перелетают к следующей реальной платформе и выделяют её; подсказка исчезает перед выполнением маршрута. Подарки сохраняются в localStorage, отдельно отображаются для каждой главы.

Акварельная сцена рисуется в Canvas из растровых PNG. Зайчонок прыгает в трёх направлениях; Лисёнок плавно машет лапой и подпрыгивает от радости. Все позы персонажей нарисованы вместе с одинаковым освещением; переходы смешиваются плавно. Восемь рыбок четырёх видов сохраняют горизонтальное положение и реагируют на касание воды. Рыбки рисуются целыми изображениями без полосовых стыков. При запоминании фон становится спокойнее. Поддерживается prefers-reduced-motion.

Музыка и звуки включены по умолчанию и запускаются после первого клика или нажатия клавиши. Кнопка с нотами выключает и включает звук. Есть звуки воды, птиц, шагов, прыжков, ошибок, отсчёта и победы, регулятор громкости и приглушение при озвучке. У Лунной речки отдельная медленная мелодия. В настройках можно выбрать доступный русский голос и прослушать пример; используются обычная высота голоса и естественный темп. Внешний сервис озвучки не подключён.

Интерфейс оформлен как спокойная книжная страница: бумажный фон, простые разделители, рисованные подарки и отдельная акварельная иконка сердечка. Эмодзи заменены авторскими иконками. При первом посещении появляется приглашение на экскурсию; его можно закрыть. Повторно тур доступен из памятки.

Кнопка «Ведущему» открывает памятку и настоящий тур из шести шагов. Подсвеченные настройки, выбор главы и звук доступны прямо внутри тура. Есть «Назад», «Дальше» и выход по Escape. Отдельная памятка — «Памятка ведущему.md».

## Запуск

Открыть «Тропа троллей.html» в браузере: стили, скрипты и семь PNG уже включены в один файл. Установка и сервер не нужны. Предыдущий вариант сохранён как «Тропа троллей — вектор.html».

Для GitHub Pages подготовлен workflow `.github/workflows/pages.yml`: тесты и сборка запускаются при пуше в `main`. Команда `npm run build` создаёт `_site/` только с файлами игры. Пошаговая настройка и команды первого пуша — в [GITHUB-PAGES.md](GITHUB-PAGES.md). Удалённый репозиторий пока не задан, публикация не выполнялась.

Кнопки уровней показывают названия, текущее положение и постоянную отметку «Пройдено» с галочкой. Рядом указан прогресс текущей главы. Настройки вынесены в отдельный блок под игровым полем и командами.

Для разработки:

```sh
python3 -m http.server 4173 --directory dist
```

Открыть http://localhost:4173. После изменений пересобрать автономный файл:

```sh
node build-standalone.mjs
```

Проверки:

```sh
node --test engine.test.mjs story.test.mjs motion.test.mjs
```

## Исходники

- dist/engine.mjs — команды, главы, уровни и состояние игры.
- dist/story.mjs — сюжеты, подарки и загадки.
- dist/motion.mjs — направления прыжков и маршруты рыбок.
- dist/scene.mjs — сцена и анимации.
- dist/tour.mjs — интерактивная памятка.
- dist/audio.mjs — синтез звука.
- dist/app.mjs, dist/index.html, dist/style.css — интерфейс.
- dist/assets — иллюстрации. Промпты встроенного ImageGen сохранены в ASSET-PROMPTS.md.

Для онлайн-занятия ведущий показывает экран в видеосвязи и нажимает команды, которые называет ребёнок. Сетевой комнаты и синхронизации между устройствами пока нет. Файлы не опубликованы в интернете.
